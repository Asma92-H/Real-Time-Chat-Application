# ChatSphere-Real-Time Chat Application

A real-time chat application built using WebSocket technology that enables instant communication between users.
Users can create accounts, join chat rooms, start private conversations, and exchange messages in real time.
The application is fully responsive and provides a smooth chatting experience across different devices.

## Features

- User Login
- Real-Time Messaging using WebSocket
- Public Chat Rooms
- Private One-to-One Chat
- Chat History
- Online/Offline User Status
- Notifications
- Multimedia File Sharing
- Profile Picture Upload
- Clear All Chats
- Responsive Design (Mobile, Tablet & Desktop)
- Message Timestamps

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Socket.IO (WebSocket)

## Future Enhancements

- Voice & Video Calling
- Message Reactions
- Message Search
- End-to-End Encryption
